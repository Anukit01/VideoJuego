
# Little Empire 🏰
*My First Game Development Journey*

## 📜 Descripción / Description
**[ES]** Little Empire es mi primer videojuego, desarrollado como un hito de aprendizaje. Es un juego de gestión de recursos y estrategia (RTS) simplificado inspirado en clásicos, enfocado en el ensamblaje de sistemas en un entorno 2D.
**[EN]** Little Empire is my first video game, developed as a learning milestone. It's a simplified RTS and resource management game inspired by classics, focusing on system assembly in a 2D environment.

## 🛠️ Tech Stack & Learning / Tecnologías y Aprendizaje
* **Engine:** Unity 2022.3.60f1 (C#)
* **Core Systems:** Finite State Machines (FSM), NavMesh 2D, Coroutines, Inheritance (OOP).
* **AI Assistance:** Utilicé herramientas de IA para auditar mi lógica y resolver errores complejos, permitiéndome entender profundamente cada línea de código ensamblada.

## 🎮 Gameplay Tips / Consejos de Juego
* **Resolution:** Optimized for 1920x1080.
* **Pro-tip:** Se puede ganar con pocas unidades. ¡Usa el botón ESC para salir con dignidad!
